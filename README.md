# 個人創作作品集 (Portfolio)

這是本學期的課堂專案作品集，記錄透過 AI（Antigravity / agy）協同創作、探索與開發的過程。

## 目錄結構
- `AGENTS.md`：AI 協作課堂公約與專案指引
- `creatures/`：虛擬生物養殖箱專案（「想你的生物」發想與設定）
- `projects/`：後續課堂程式與互動作品

## 開始使用
在專案根目錄開啟終端機並啟動 agy：
```powershell
cd C:\Users\admin\Documents\GitHub\portfolio
agy
```
