# 個人創作作品集 (Portfolio)

世界觀：
人類消失5,000萬年後，一顆自帶超強磁場的黑洞闖進太陽系，直接把太陽吞了。當它從地球旁邊擦身而過時，強大的引力直接把地殼撕裂，引發全球超大地震和火山大爆發。地底的噴發岩漿直接把整座海洋煮沸，海水瞬间變成籠罩地表的高溫高壓水蒸氣，還混合了大量的硫磺，並下起酸雨。同時引力的拉扯讓有些地方陸地飛上了天，變成「懸浮島」；有些地方重力卻變得超級重，連站著都會被壓垮。
黑洞的狂暴磁場直接撞擊地球的地核，把原本保護地球的磁場徹底砸碎。少了磁場保護，宇宙輻射直接轟炸大氣層，讓天空整天都在高壓放電，閃爍著紫綠色的極光。地底被磁化的鐵礦碎片也被磁場吸到半空中，順著狂風瘋狂狂飆，變成像高壓噴砂機一樣的「鐵砂暴」，能直接把地表的所有東西割碎。

誕生出的全新異化生物類型：
浮晶籠
特徵與棲地：懸浮於負重力懸浮島高空，呈會呼吸的幾何多面體籠狀。
適應器官：多面玻璃籠包裹熱氣囊漂浮，伸出晶體天線與離子鬚吸取極光與風暴電荷，存入生物電容囊。
群居策略：串聯天線形成導電網分擔過載電擊，代價是目標過大易招天敵。
多產不育幼：隨風暴釋放數萬顆靜電玻璃孢子，靠數量抵禦高空淘汰。

磁甲重力獸
特徵與棲地：棲息於高重力地層，身體高度扁平，配有厚重液壓肢體。
適應器官：金屬外骨骼背甲可抗高重力與磁化鐵砂暴，並將鐵砂摩擦動能轉化為電能。
獨居策略：獨佔微薄資源並避免遭鐵砂暴集體掃滅，代價是極難尋獲配偶。
少產久育幼：數年產一卵於腹囊。母獸硬抗重力與鐵砂暴，並以背甲轉化的電能「充電」育幼，待其發育完全才放獨立。

熱脈蒸氣植物
特徵與棲地：棲息於岩漿溝與高溫噴發口，呈金屬肉質與晶透膠質交織的流體花朵狀。
適應器官：液壓耐酸肉質根莖深紮岩縫吸收地熱，靠體內高壓流體與矽膠薄膜抗衡強酸與高壓。
群居策略：密集成簇共享地熱噴口溫差，代價是噴口熄滅時集體死亡。
多產不育幼：順著高溫蒸氣噴射大量耐酸孢子，隨氣流擴散至新噴口。
